# JPEG-LS 生态查重

检索日期为 2026-11-23（新加坡时间）。在已检查的公开范围内未发现直接的纯 MoonBit JPEG-LS 编解码实现。检索对象是实现 ITU-T T.87 / ISO/IEC 14495-1 正则模式和游程模式的 JPEG-LS 编解码器，定位时同时看 SOF55 (`0xFFF7`)、预测与熵解码路径。JPEG 的 DCT/Huffman 实现、JPEG 2000 和 JPEG XL 属于不同标准。 [JPEG 委员会对 JPEG-LS 的说明](https://jpeg.org/jpegls/) · [ITU-T T.87](https://www.itu.int/rec/T-REC-T.87-199806-I/en)

## 检索方法

- 用 Moon CLI `0.1.20261119` 连接 Mooncakes 执行 `moon search --limit 6 '<词>'`，分别查 `JPEG-LS`、`JPEG LS`、`jpegls`、`LOCO-I`、`CharLS`、`14495`、`SOF55`。前两个查询各得到 4 个结果，包括 JPEG XL、算法集、医学图像工具和脉冲神经网络库。`jpegls` 的 2 个结果是照片归并工具及 JPEG 库。`CharLS` 的 6 个结果包含字符编码和 MIME 等相关拼写。另三个术语无模块结果。定向查询 `image.codec`、`moonimage` 和 `moonbit_image`，并用 `moon view` 核对独立发布的 `walkzzz/image.codec@0.1.0`。 [Mooncakes 登记库](https://mooncakes.io/)
- GitHub 仓库搜索分别使用 `"<词>" moonbit in:name,description,readme` 和以上七个词，完成的六个查询均为零命中，`JPEG LS` 查询受匿名请求限额影响。GitHub 全站源代码 API 的 `"<词>" extension:mbt` 匿名查询均返回 401。补用公开网页索引查询 `site:github.com`、MoonBit、`.mbt` 和上述术语组合，随后直接下载近邻仓库的固定 SHA 快照，扫描 `.mbt`、`.mbti`、README 和项目配置中的相关术语，并打开格式矩阵与实现路径核对。全站源码索引覆盖无法确认，固定版本以表中 SHA 为准。 [GitHub 仓库查询接口](https://docs.github.com/en/rest/search/search#search-repositories) · [GitHub 代码查询接口](https://docs.github.com/en/rest/search/search#search-code)
