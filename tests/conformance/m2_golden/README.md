# M2 Independent Reference Golden Fixtures

This directory holds a frozen representative subset of independent T.87 M2 reference vectors extracted from `reports/t87-m2-20261125/synthetic-matrix-manifest.json` for fast three-backend CI regression (`scripts/verify_m2_golden.mjs`).

## Provenance

- **HP JPEG-LS V.1.00 reference streams**: Generated by ITU-T's official T.87 HP V.1.00 reference software (`jlsrefV100.zip`, SHA-256 `085285f0552ef0b6ebcf29bc5a6d3bc0d6bda0408e9f2f1c138be2e55200814f`). For cases where `P > max(2, bit_length(MAXVAL))` (such as `P=9, MAXVAL=255` and `P=12, MAXVAL=1000`), only the SOF55 `P` field and explicit LSE1 fields are adapted while keeping the HP entropy segment intact.
- **T.87 Annex A 1×1 analytic vectors** (`p2-m1-n0`, `tiny-p2-m1-n0-s0`, `p2-m2-n0`, `p2-m2-n1`): Derived directly from T.87 Annex A run-interruption and Golomb-Rice coding rules for `MAXVAL` 1 and 2 (which HP V.1.00 rejects).
- **Zero MoonJLS-generated expectations**: None of `.input.raw`, `.reference.jls`, `.reference.raw`, or `lse-*.jls` are generated by MoonJLS, and `manifest.json` hashes are never auto-updated.

## Coverage

- **12 positive golden cases**: `P=2, MAXVAL=1` (`0`/`1` samples), `P=2, MAXVAL=2` (`NEAR=0`/`1`), `P=9, MAXVAL=255` (`NEAR=0`/`1`), `P=8, MAXVAL=255` baseline, non-full-range `MAXVAL` (`5`, `97`, `256`, `1000`, `65534`), and custom LSE1 `T1/T2/T3/RESET` presets.
- **18 LSE1 wire variants**: `lse-before-sof`, `lse-last-definition-wins`, `lse-zero-resets-prior-definition`, `lse-explicit-defaults`, `lse-mixed-zero-fields`, plus 13 rejected boundary/malformed/out-of-scope streams.
- **7 invalid encode boundary inputs**: `P` out of range, `MAXVAL > 2^P-1`, `NEAR > floor(MAXVAL/2)`, sample `> MAXVAL`, threshold order violation, `RESET > 255`.

Run locally:

```sh
node sdk/build.mjs
node scripts/verify_m2_golden.mjs
```

Add Native CLI verification by passing `--native-exe <path/to/moonjls>` (plus `--native-wsl Ubuntu-22.04` when invoking a WSL-built binary from Windows).
